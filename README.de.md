## AI-Design-Workflow neu definieren

Starry definiert den Workflow neu, indem es die Leinwand intelligent, überprüfbar und nahtlos mit deinem Code verbindet.

| Funktion | Beschreibung |
|---|---|
| **KI-gesteuerte Leinwand** | Basierend auf dem Agent Client Protocol (ACP). Chatte direkt mit der Leinwand. KI liest, schreibt und erzeugt nativ Auto-Layout-Designsysteme aus natürlicher Sprache. |
| **MCP-Server** | Verbindet sich nahtlos mit KI-Coding-Tools wie Cursor und Claude über das Model Context Protocol. Erzeuge präzisen UI-Code, ohne den Editor zu verlassen. |
| **CLI für CI/CD** | Design-Dateien sind Code. Nutze die CLI, um Assets stapelweise zu exportieren, Typografie-Verstöße zu erkennen und Designänderungen automatisch beim Code-Review zu vergleichen. |
| **Vollständige Datenkompatibilität mit Figma** | Starry bleibt perfekt mit Figma synchron. Kopiere von einer Leinwand, füge in die andere ein — Frames, Texte, Komponenten und Stile übernehmen sich originalgetreu. Keine Lock-in, keine Blackbox. |

## Starry verwandelt einen Satz in ein Interface

Kein Code, keine leere Leinwand — beschreibe das Interface, das du willst, und Starrys KI generiert es für dich.

| Szenario | Warum |
|---|---|
| SaaS- / Web-App-UI (Einstellungen, CRUD, Formulare) | Jedes Softwareteam baut das — Auto-Layout plus direkter React (JSX) -Export halten den Loop am kürzesten. |
| Marketing-Landingpage / Website | Ein Muss für jedes Produkt und jeden Startup — ein Satz rein, HTML/React raus. |
| Daten-Dashboard / Admin-Panel | Die größte Kategorie im B2B — Tabellen, Karten und Diagramme sind alle Stärken des Auto-Layouts. |
| Mobile-App-UI (Login, E-Commerce, Onboarding) | Riesige Nachfrage — positioniert als Design + Prototyp, mit HTML-Export für die Übergabe. |
| Designsystem / Komponentenbibliothek | 'Ein Designsystem aus natürlicher Sprache generieren' — das stärkst differenzierende Argument. |
| Schneller Prototyp / MVP-Validierung | Prompt → Oberfläche → Code: der schnellste Weg für Indie-Entwickler und PMs, Ideen zu validieren. |

## Häufig gestellte Fragen

**Kann Starry mit AI eine Oberfläche erzeugen?**

Ja. Beschreiben Sie mit eigenen Worten, was Sie wollen, und Starrys KI erzeugt die Oberfläche - Layout, Komponenten und Auto-Layout - und exportiert produktionsreifen Code (React (JSX) und HTML). Eine echte, bearbeitbare, lauffähige UI, kein statisches Mockup.

**Kann ich meine bestehenden Figma-Dateien importieren?**

Ja. Starry importiert native .fig-Dateien - Vektoren, Texte und Stile werden originalgetreu übernommen, und du kannst in beiden Tools weiterarbeiten.

**In welche Frameworks kann ich exportieren?**

React (JSX) und reines HTML – alle mit Layout-Treue zwischen Canvas und generiertem Code. Deine Codebasis besitzt die Ausgabe.

**Wie funktioniert die MCP-Integration?**

Starry betreibt einen MCP-Server, der KI-Coding-Tools wie Cursor, Claude Code und Codex Lese- und Schreibzugriff auf den Canvas gewährt. Erzeuge UI-Code aus deinem Editor, ohne den Kontext zu wechseln.

**Sind meine Designdaten privat?**

Starry ist lokal-first. Deine Dateien bleiben standardmäßig auf deinem Rechner und können mit Git versioniert werden. Die Cloud-Zusammenarbeit ist optional und Ende-zu-Ende verschlüsselt.

**Wo bekomme ich Starry?**

Lade die macOS-App von starry.design oder öffne die Browser-Version auf trial.starry.design – keine Installation, keine Registrierung.

## Inhalt des Repositorys

Starter-Prompts, Design-System-Spezifikationen und Beispiele für Starry. Kein Anwendungsquellcode – die App bleibt proprietär.

```
starry-templates/
├── README.md                 # this file (+ 12 localized versions)
├── assets/                   # hero image & real editor screenshots
├── design-systems/
│   └── base-ui.md            # sample Markdown design-system spec
├── prompts/
│   ├── landing-page.md       # marketing landing page
│   ├── saas-settings.md      # settings console with members table
│   ├── analytics-dashboard.md
│   └── mobile-login.md       # login + OTP + onboarding screens
└── docs/
    ├── comparison.md         # Starry vs Figma / Stitch / Sketch
    └── design-to-code.md     # export pipeline & guarantees
```

## Verwendung

1. Starry öffnen — Desktop-App oder Browser-Version.
2. Eine Design-System-Spec aus `design-systems/` einfügen, dann einen Prompt aus `prompts/`.
3. Starry erzeugt editierbare Auto-Layout-Ebenen — als React (JSX) oder HTML exportieren.
