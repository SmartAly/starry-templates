## Redéfinir votre workflow de design IA

Starry redéfinit le flux de travail en rendant le canevas intelligent, vérifiable et connecté de façon transparente à votre base de code.

| Fonctionnalité | Description |
|---|---|
| **Canevas piloté par IA** | Basé sur le Agent Client Protocol (ACP). Discutez directement avec le canevas. L'IA lit, écrit et génère nativement des systèmes de design en auto design à partir du langage naturel. |
| **Serveur MCP** | Se connecte de façon transparente à des outils de code IA comme Cursor et Claude via le Model Context Protocol. Génère du code UI précis instantanément sans quitter votre éditeur. |
| **CLI pour CI/CD** | Les fichiers de design sont du code. Utilisez la CLI pour exporter des ressources en lot, détecter les violations typographiques et comparer les changements de design automatiquement lors de la revue de code. |
| **Parité totale des données avec Figma** | Starry reste parfaitement synchronisé avec Figma. Copiez d'un canvas, collez dans l'autre — cadres, textes, composants et styles sont conservés avec une fidélité totale. Aucune dépendance, aucune boîte noire. |

## Starry transforme une phrase en interface

Pas de code, pas de canvas vierge — décris l'interface que tu veux et l'IA de Starry la génère pour toi.

| Scénario | Pourquoi |
|---|---|
| UI SaaS / app web (paramètres, CRUD, formulaires) | Toutes les équipes logicielles les construisent — l'auto-layout et l'export direct vers React (JSX) gardent la boucle la plus courte. |
| Page d'accueil marketing / site web | Indispensable pour tout produit et toute startup — une phrase entrée, HTML/React sorti. |
| Tableau de bord de données / panneau d'admin | La plus grande catégorie en B2B — tableaux, cartes et graphiques sont tous des points forts de l'auto-layout. |
| UI d'app mobile (connexion, e-commerce, onboarding) | Demande énorme — positionnée comme design + prototype, avec export HTML pour la livraison. |
| Système de design / bibliothèque de composants | 'Générer un système de design à partir du langage naturel' — l'argument le plus différenciant. |
| Prototypage rapide / validation MVP | Prompt → interface → code : le chemin le plus rapide pour que les devs indépendants et les PM valident des idées. |

## Foire aux questions

**Starry peut-il générer une interface avec l'IA ?**

Oui. Décrivez ce que vous voulez en langage naturel et l'IA de Starry génère l'interface - mise en page, composants et auto-layout - puis exporte du code prêt pour la production (React (JSX) et HTML). Une vraie UI éditable et exécutable, pas un mockup statique.

**Puis-je importer mes fichiers Figma existants ?**

Oui. Starry importe les fichiers natifs .fig - vecteurs, textes et styles sont conservés fidèlement, et vous pouvez continuer à ajuster dans l'un ou l'autre outil.

**Vers quels frameworks puis-je exporter ?**

React (JSX) et HTML pur — tous avec une parité de mise en page entre le canevas et le code généré. Votre base de code possède le résultat.

**Comment fonctionne l'intégration MCP ?**

Starry exécute un serveur MCP qui donne aux outils de codage IA comme Cursor, Claude Code et Codex un accès en lecture/écriture au canevas. Générez du code UI depuis votre éditeur sans changer de contexte.

**Mes données de design sont-elles privées ?**

Starry est local-first. Vos fichiers restent sur votre machine par défaut et peuvent être versionnés avec Git. La collaboration cloud est optionnelle et chiffrée de bout en bout.

**Où l’obtenir ?**

Téléchargez l’app macOS sur starry.design ou ouvrez l’essai navigateur sur trial.starry.design — sans installation ni inscription.

## Utilisation

1. Ouvrez Starry — l’app de bureau ou l’essai navigateur.
2. Collez une spec de design system depuis `design-systems/`, puis un prompt depuis `prompts/`.
3. Starry génère des calques auto-layout modifiables — exportez en React (JSX) ou HTML.
