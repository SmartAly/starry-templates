## अपने AI डिज़ाइन वर्कफ़्लो को फिर से परिभाषित करें

Starry कैनवास को बुद्धिमान, सत्यापन योग्य बनाकर और आपके कोडबेस से निर्बाध रूप से जोड़कर वर्कफ़्लो को फिर से परिभाषित करता है।

| सुविधा | विवरण |
|---|---|
| **AI-संचालित कैनवास** | Agent Client Protocol (ACP) पर आधारित। कैनवास के साथ सीधे चैट करें। AI प्राकृतिक भाषा से स्वचालित लेआउट डिज़ाइन सिस्टम को स्वाभाविक रूप से पढ़ता, लिखता और बनाता है। |
| **MCP सर्वर** | Model Context Protocol के माध्यम से Cursor और Claude जैसे AI कोडिंग टूल से निर्बाध रूप से जुड़ता है। अपना एडिटर न छोड़ते हुए तुरंत सटीक UI कोड बनाएं। |
| **CI/CD के लिए CLI** | डिज़ाइन फ़ाइलें कोड हैं। संपत्तियों को बैच में निर्यात करने, टाइपोग्राफी उल्लंघनों का पता लगाने और कोड समीक्षा के दौरान डिज़ाइन परिवर्तनों की स्वचालित तुलना करने के लिए CLI का उपयोग करें। |
| **Figma के साथ पूर्ण डेटा समानता** | Starry Figma के साथ हमेशा सिंक रहता है। एक कैनवास से कॉपी करें, दूसरे में पेस्ट—फ़्रेम, टेक्स्ट, कंपोनेंट और स्टाइल वैसे ही रहते हैं। कोई लॉक-इन नहीं, कोई ब्लैक बॉक्स नहीं। |

## Starry एक वाक्य को इंटरफ़ेस में बदल देता है

कोई कोड नहीं, कोई खाली कैनवास नहीं — जो इंटरफ़ेस आप चाहते हैं उसे बस बताएं, और Starry का AI उसे आपके लिए बना देता है।

| परिदृश्य | क्यों |
|---|---|
| SaaS / वेब ऐप UI (सेटिंग्स, CRUD, फ़ॉर्म) | हर सॉफ़्टवेयर टीम इन्हें बनाती है — ऑटो-लेआउट और सीधा React (JSX) एक्सपोर्ट लूप को सबसे छोटा रखता है। |
| मार्केटिंग लैंडिंग पेज / वेबसाइट | हर प्रोडक्ट और स्टार्टअप के लिए अनिवार्य — एक वाक्य अंदर, HTML/React बाहर। |
| डेटा डैशबोर्ड / एडमिन पैनल | B2B में सबसे बड़ी श्रेणी — टेबल, कार्ड और चार्ट सभी ऑटो-लेआउट की ताकत हैं। |
| मोबाइल ऐप UI (लॉगिन, ई-कॉमर्स, ऑनबोर्डिंग) | बहुत बड़ी माँग — डिज़ाइन + प्रोटोटाइप के रूप में, हैंडऑफ़ के लिए HTML एक्सपोर्ट के साथ। |
| डिज़ाइन सिस्टम / कंपोनेंट लाइब्रेरी | 'प्राकृतिक भाषा से डिज़ाइन सिस्टम जनरेट करें' — सबसे भिन्नीकृत दांव। |
| त्वरित प्रोटोटाइप / MVP सत्यापन | प्रॉम्प्ट → इंटरफ़ेस → कोड: इंडी डेव और PM के लिए विचार सत्यापित करने का सबसे तेज़ रास्ता. |

## अक्सर पूछे जाने वाले प्रश्न

**क्या Starry AI से इंटरफेस बना सकता है?**

हाँ। अपनी भाषा में बताइए कि आपको क्या चाहिए और Starry का AI इंटरफ़ेस बना देता है — लेआउट, कंपोनेंट, ऑटो-लेआउट — और प्रोडक्शन-रेडी कोड (React (JSX) और HTML) एक्सपोर्ट करता है। यह एक स्थिर मॉकअप नहीं, बल्कि असली, एडिट करने योग्य और चलाने योग्य UI है।

**क्या मैं अपनी मौजूदा Figma फ़ाइलें आयात कर सकता हूँ?**

हाँ। Starry नेटिव .fig फ़ाइलें सीधे इम्पोर्ट करता है—वेक्टर, टेक्स्ट और स्टाइल पूरी तरह रहते हैं, और आप किसी भी टूल में एडिट जारी रख सकते हैं।

**मैं किन फ़्रेमवर्क में निर्यात कर सकता हूँ?**

React (JSX) और शुद्ध HTML — कैनवास और जेनरेट कोड के बीच लेआउट समानता के साथ। आउटपुट आपकी कोडबेस का है।

**MCP एकीकरण कैसे काम करता है?**

Starry एक MCP सर्वर चलाता है जो Cursor, Claude Code और Codex जैसे AI कोडिंग टूल को कैनवास पर पढ़ने-लिखने का अधिकार देता है। बिना कॉन्टेक्स्ट बदले अपने एडिटर से UI कोड जेनरेट करें।

**क्या मेरा डिज़ाइन डेटा निजी है?**

Starry लोकल-फ़र्स्ट है। आपकी फ़ाइलें डिफ़ॉल्ट रूप से आपकी मशीन पर रहती हैं और Git से वर्शन की जा सकती हैं। क्लाउड सहयोग वैकल्पिक है और एंड-टु-एंड एन्क्रिप्टेड है।

**यह कहाँ मिलेगा?**

macOS ऐप starry.design से डाउनलोड करें, या trial.starry.design पर ब्राउज़र में आज़माएँ — इंस्टॉल और साइनअप की ज़रूरत नहीं।

## रिपॉज़िटरी में क्या है

Starry के लिए तैयार प्रॉम्प्ट, डिज़ाइन-सिस्टम स्पेक और उदाहरण। ऐप का सोर्स कोड शामिल नहीं — ऐप निजी रहता है।

```
starry-templates/
├── README.md                 # this file (+ 12 localized versions)
├── assets/                   # hero image & real editor screenshots
├── design-systems/
│   └── base-ui.md            # sample Markdown design-system spec
├── prompts/
│   ├── landing-page.md       # marketing landing page
│   ├── saas-settings.md      # settings console with members table
│   ├── analytics-dashboard.md
│   └── mobile-login.md       # login + OTP + onboarding screens
└── docs/
    ├── comparison.md         # Starry vs Figma / Stitch / Sketch
    └── design-to-code.md     # export pipeline & guarantees
```

## उपयोग कैसे करें

1. Starry खोलें — डेस्कटॉप ऐप या ब्राउज़र ट्रायल।
2. `design-systems/` से डिज़ाइन-सिस्टम स्पेक पेस्ट करें, फिर `prompts/` से प्रॉम्प्ट।
3. Starry एडिटेबल auto-layout लेयर बनाता है — React (JSX) या HTML में एक्सपोर्ट करें।
