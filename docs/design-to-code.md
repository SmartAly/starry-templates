# From design to production code

Designs are never stranded. Starry turns any artboard into clean, handoff-ready React (JSX) and
HTML — pixel-perfect and ready to ship.

```
design.pen  →  index.html / Component.jsx
```

## What the export guarantees

| Guarantee | What it means |
|---|---|
| **Pixel-perfect** | Layout, spacing, and style tokens transfer exactly as designed. |
| **Multi-framework** | Export React (JSX) and HTML. |
| **Round-trip editable** | Keep editing in code or canvas — Starry stays in sync both ways. |

## The loop

1. **Describe it.** Write what you want in natural language — "a pricing page with three tiers".
2. **Generate it.** Starry produces a real, editable UI on an AI-driven canvas (ACP).
3. **Ship it.** Export React (JSX) or HTML, or push the result into your editor over MCP.

## Bring it into your editor

Starry runs an MCP (Model Context Protocol) server, so AI coding tools such as Cursor, Claude Code
and Codex can read and write your canvas — generate UI code from your editor without switching
context.

## Existing Figma files

Starry imports native `.fig` files: vectors, text, and styles transfer faithfully, and you can keep
refining in either tool.
